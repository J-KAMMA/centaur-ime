# Centaur IME の言語を増やす設計（下書き）

2026-11-06。決まったことは共有記憶の「現行方針」が正本で、この文書はそれを作り方に落としたもの。

## 1. 形

- **箱は 1 つ**: インストーラー、更新、新しい版のお知らせ、設定画面、辞書の更新は全言語で共有する。
- **言語は選んで入れる**: 入れるときに選び、後から足し外しできる。AI の模型と大きい辞書（日本語の辞書など）は、
  選んだ言語の分だけ落とす。
- **キーボードの一覧には言語ごとの項目**:
  - 日本語: 今の Mozc の画面（「Centaur IME 日本語」）
  - 英語・中国語・韓国語: 共通の小さい画面（新しく作る）
- **日本語版の IME オフ（半角英数）は英語版の動きにする**: キーはすぐアプリに渡し、補完は Tab のときだけ、
  直しは候補を見せるだけ。パスワード欄・ターミナル・ゲームでは今の素通しに戻す。

## 2. 部品

```
native/centaur_core/      言語に共通の芯（C++、AI なし）
  core.{h,cc}             語の表、区切り（ビタビ）、キーの位置を見た直し、補完
  hangul.{h,cc}           ハングルと 2 ボル式のキーの行き来
  （中国語）               拼音の音節の区切りと直しは core の区切り・直しを音節の表で使う
tools/en_ime, ko_ime, zh_ime   計測と表づくり（Python。芯と同じ計算の試作を持ち、一致を試験する）
```

言語ごとに違うのは「字の単位」と「表」だけにする。

| 言語 | 字の単位 | 区切り | 直し | 補完 |
|---|---|---|---|---|
| 英語 | 英字 | スペースなしの文を単語に | 単語（キーの位置） | 単語の頭から |
| 韓国語 | 音節（キーは 2 ボル式） | 分かち書き（字と字の間ごと） | 字母のキーの位置、英語モードのまま打った語 | 語の頭から |
| 中国語 | 拼音の英字 → 漢字 | 拼音の音節 | 拼音の打ち間違い（キーの位置） | 確定した後の次の語（联想） |

中国語の漢字への変換そのものは Rime（librime、BSD-3）を土台にし、その上に同音字の手がかりと小さい模型を足す。

## 3. 一致の試験（芯を書き替えるときの決まり）

芯（C++）は試作（Python）と同じ問いに同じ答えを出すことを、GitHub の計測の流れで毎回確かめる。

- 英語: `tools/en_ime/parity.py`（区切り・直し・補完。ふつうの文と境目の問い）
- 韓国語: `tools/ko_ime/hangul_parity.py`（全音節と、でたらめなキーの並び）

同点のときは語の順で決める（両方で同じ答えにするため）。

## 4. 速さ

- 打ったキーがアプリに届くまでの遅れは、今の素通しと変えない（直しと補完は後ろで計算し、候補を出すだけ）。
- 芯の 1 回の計算の時間は計測の流れで出す（`out/parity.txt`）。速くする話は `speed-claims` の決まりを通す。
