# 共通の箱: インストーラー、言語パック、更新、設定

## 1. 決まっていること

- インストーラーは 1 つ。入れるときに言語を選び、後から足し外しできる。
- AI の模型と大きい辞書は、選んだ言語の分だけ落とす。
- 新しい版のお知らせ、更新、設定画面、辞書の更新は全言語で 1 つ。
- 外すときも学習のデータは消さない（今と同じ。名前替えの写しの決まりと合わせる）。

## 2. 分け方: 本体と言語パック

| 入れ物 | 中身 | 配り方 |
|---|---|---|
| 本体（MSI） | 窓口（Mozc の TIP、共通の TIP）、常駐、芯、設定画面、更新の道具 | 配布ページの MSI。署名付き |
| 言語パック | その言語の表・辞書・模型（大きいもの） | 本体が初めて使うときに落とす。オフライン用の zip も配る |

**小さい物は本体に入れる。** 例: 英語の芯の表（組み立て済みで 20 MB 以下を目標）、ハングル・Telex の組み立て
（コードだけ）。理由: 落とすのに失敗しても最低限は動くように。

**大きい物はパックにする。** 例: zenz の模型、日本語の大きい辞書、中国語の模型、Rime の辞書。

MSI の「機能（Feature）」を言語ごとに分ける。選ばなかった言語は TIP の登録をしない（キーボードの一覧に出ない）。
後から足すときは「アプリ → Centaur IME → 変更」で機能を足す（MSI の標準の動き。自前の画面は要らない）。

## 3. 言語パックの形

```
packs/<言語>/<版>/
  manifest.json      名前、版、必要な本体の最小の版、ファイルの一覧（名前・大きさ・SHA-256）
  manifest.sig       manifest.json への署名
  files...
packs/<言語>/current 今使っている版の名前（1 行）
```

- 置き場: `%LOCALAPPDATA%\CentaurIME\packs`（ウィンドウズ）、`~/Library/Application Support/CentaurIME/packs`（マック）、
  `$XDG_DATA_HOME/centaur-ime/packs`（Linux）。
- **入れ替えは一度に**: 新しい版を別のフォルダに全部落として確かめてから、`current` を書き替える。
  途中で止まっても前の版が残る。古い版は次に起きたときに消す（使っていなければ）。
- **署名**: 今の辞書の更新と同じ作り（manifest に SHA-256、manifest 全体に署名）。鍵は辞書の鍵とは**別に作る**
  （パックの鍵が漏れても辞書を偽れないように）。秘密の鍵は GitHub の秘密の値と手元の控えだけに置く（辞書の鍵と同じ扱い）。
- manifest の魔法の文字列は新しく決める（`centaur-ime-pack-manifest`）。辞書の `compound-ime-dict-manifest` は変えない。

## 4. 落とし方

- 出どころは GitHub の配布ページ（release）の添付ファイル。URL は manifest に書き、本体には「配布ページの場所」だけ持つ。
- 途中から再開できるように Range で取る。大きさと SHA-256 を確かめてから置く。
- 空きが足りないときは落とし始めない（大きさは manifest に書いてある）。
- 送るのは GET と User-Agent（`CentaurIME-pack/1`）だけ。打った文字や使い方は送らない。
- オフラインの人向け: パックの zip を配布ページに置き、設定画面の「ファイルから入れる」で入れられるようにする
  （中身の確かめは同じ）。

## 5. 更新

| 物 | 確かめる頻度 | 入れ方 |
|---|---|---|
| 本体 | 1 日 1 回（今の update-check） | お知らせを出すだけ。入れるのは利用者 |
| 辞書 | 今のまま | 今のまま（設定で止められる） |
| 言語パック | 本体と同じ時に確かめる | 設定で「自動で入れる」を選べる（初めは「お知らせだけ」） |

本体が古すぎて新しいパックを使えないとき（manifest の最小の版より古い）は、パックを入れずに本体の更新を勧める。

## 6. 設定画面

- 今の Mozc の設定（Qt）を土台に、言語ごとの頁を足す（Qt はすでに配っている）。
- 共通の頁: 言語パックの一覧と状態（入っている版、大きさ、更新があるか、消す）、更新の設定、使い方の記録を見る・消す。
- 言語の頁: その言語の設定（例: 英語の補完の Tab、直しの候補の出し方、素通しにするアプリ）。

## 6.5 言語の切り替え

入れた言語どうしの切り替えは、OS の切り替えに加えて IME の中の切り替えのキー（Ctrl＋Shift＋Space の案）で回せる。
回す言語と順は設定画面の共通の頁で選ぶ。詳しくは 02-tsf-frontend.md の 7 章。

## 7. 名前替えとの関係

- 旧名（CompoundIME）の置き場からの写しは、名前替えの版で常駐が最初に起きたときに済む。パックの置き場は新しく作る
  ので写しは要らない。
- zenz の模型は今は本体の常駐が落としている。言語パックの仕組みができたら「日本語パック」に移す。
  そのときも、すでに落とした模型を置き場ごと引き継ぐ（落とし直さない）。

## 8. まだ決めていないこと

- マックの pkg で「言語を選んで入れる」をどう見せるか（pkg の選び方の画面か、入れた後に設定で選ぶか）。
- Linux（ibus）でのパックの扱い（配布物に含めるか、同じく落とすか）。
- Microsoft Store 版を出すかどうか（出すならパックの置き場と更新が Store の決まりに縛られる）。
