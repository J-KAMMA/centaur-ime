# 小さな模型の計画

## 1. 決まっていること

- zenz は日本語専用。ほかの言語は、それぞれ小さな模型を自分たちで学習させる。
- 大きさは zenz と同じくらいか、それより小さく（Qwen 0.6B のような大きいものは使わない）。
- 変換を遅くしない。模型は「AI なしの土台」の上に乗せ、模型が無くても・間に合わなくても土台の答えで動く。
- 学習は Colab（ユーザーが押す所があるので、始める前に聞く）。結果は出力で確かめる（ページの文字では確かめない）。

## 2. 共通の作り

**動かし方**: zenz と同じく llama.cpp（GGUF、Q5_K_M）で動かす。日本語で組み立て・配布・速さの測り方がすでにあるので、
同じ道具を使い回す。

**入出力の形**（zenz に合わせる）:
```
<入力の始め>入力の文字<出力の始め>出力の文字<終わり>
```
- 字の単位で区切る（語の単位にしない）。字の種類が少なく、表に無い語にも強いため。
- 前の文脈（前に確定した文字）を入力の前に足せる形にしておく（日本語の zenz の文脈と同じ考え方）。

**出す答えを縛る**: 模型が自由に文字を出すのではなく、土台が作った「あり得る字」の中から選ばせる。
- 中国語: その音節の読みを持つ漢字だけ。
- ベトナム語: その音節の記号を外した形が同じ音節だけ。
- ヒンディー語・アラビア語: 縛らない（表に無い語を作るのが役目）が、出した字の並びがローマ字と合うかを確かめる。
こうすると、模型がおかしな字を出さず、探す範囲が狭いので速い。

## 3. 言語ごとの模型

| 言語 | 役目 | 大きさの目安 | 学習の材料 | 確かめ |
|---|---|---|---|---|
| 中国語 | 拼音（声調なし）→ 漢字。Rime の答えを直す | 20〜90M | 中国語ウィキペディア（簡体字に直す）、Tatoeba の手がかり選びの側、Pinyin2Hanzi の材料（Apache-2.0、声調を外す）| Tatoeba の確かめの枠で字の誤り（Rime 12.9%）|
| ベトナム語 | 記号なしの音節 → 記号つき | 10〜30M | ウィキペディア、Tatoeba の表づくりの側 | 会話の文で文が全部合った（いま 66.2%）|
| ヒンディー語 | ローマ字の語 → デーヴァナーガリー（前の語を見る）| 5〜20M | Dakshina の語の組（train）、ローマ字の文（dev）、ウィキの文から作った打ち方の揺れ | Dakshina の test（いま語 68.5%）|
| アラビア語 | Arabizi → アラビア文字（方言ごと）| 5〜20M | 公開の Arabizi の組、方言の文から作った Arabizi | 本物の Arabizi の試験だけ |
| 韓国語 | 分かち書き（字と字の間ごとに空白か）| 1〜5M | ウィキペディア | 会話の文で文が合った（いま 68.8%、kiwipiepy 77.3%）|

## 4. 打ち方の揺れを作る（材料を増やす）

ローマ字で打つ言語は、人によって綴りが揺れる（ヒンディー語: hai / hain / he、アラビア語: 3 / a）。
1. 本物の組（Dakshina、Arabizi の組）から「元の文字 → ローマ字」の揺れ方を数える。
2. その揺れ方で、ウィキの文から打ち方の違うローマ字を作り、材料を増やす。
3. 試験には本物の組だけを使う（作った物で測らない）。

## 5. 速さの決まり

- 1 回の変換で模型に使える時間の上限を決め、超えたら土台の答えを出す（日本語の zenzai の締め切りと同じ考え方）。
- 測るのは「キー 1 つあたりの遅れ」と「確定までの時間」。模型を足す前と後で、全体試験と同じ物差しで比べる。
- 速くする話は speed-claims の決まり（全体の時間に占める割合と、上限の見積もり）を通してから作る。

## 6. 学習の進め方（毎回同じ）

1. GitHub の流れで材料を作り、数を確かめる（文の数、字の種類、試験との重なりが 0 であること）。
2. Colab で学習（始める前に聞く）。Google ドライブの接続を飛ばさない。出力のファイルの大きさと中身で終わりを確かめる。
3. GGUF に直し、GitHub の流れで計測（土台との比べ、悪くなった所の一覧）。
4. 悪くなった所を見てから入れるか決める。

## 7. 順番

1. 中国語（4 言語に入っていて、土台の伸びしろが一番大きい）
2. ヒンディー語（候補の一番。表では 27% が埋まらない）
3. ベトナム語、アラビア語、韓国語の分かち書き（土台を伸ばしてから、届かない分を模型で）
