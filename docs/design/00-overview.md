# Centaur IME の設計: 全体の地図と作る順番

2026-11-06 の下書き。決まったことの正本は共有記憶の「現行方針」。ここはそれを作り方に落としたもの。
数字は、この日までに GitHub の計測の流れで測ったもの（出どころは各文書に書く）。

## 1. 何を作るか

**一つの箱に、言語を入れて使う入力の仕組み。** 名前は「Centaur IME」（人に見せる名前）、中の名前は CentaurIME。

| 言語 | 打ち方 | 中身（いま） | この先 |
|---|---|---|---|
| 日本語 | ローマ字 → かな漢字 | Mozc ＋ zenz（AI）＋ 同音語の手がかり | 手がかりの自動化、学習の改善 |
| 英語 | 英字そのまま | 語の表（AI なし）: 補完・直し・スペースなしの区切り | IME オフの標準、TSF の窓口 |
| 中国語（簡体字） | 全拼・簡拼・模糊音 | Rime ＋ 同音字の手がかり | 小さな模型（拼音 → 漢字） |
| 韓国語 | 2 ボル式 | 組み立て ＋ 分かち書きの直し ＋ 英語モードの見分け | 表を大きく、直しの窓 |
| 候補: ヒンディー語 | ローマ字 → デーヴァナーガリー | 組の表 ＋ 並び（語 68.5%） | 字の単位の小さな模型 |
| 候補: アラビア語 | Arabizi → アラビア文字 | 組の表 ＋ 並び（方言で語 70%） | 方言ごとの表、右から左の表示 |
| 候補: ベトナム語 | Telex・記号なし | 組み立て ＋ 記号を戻す（文 66%） | 記号なしで打つ書き方 |
| 候補: 繁体字中国語 | 注音（大千式） | 計測がまだ動いていない | Rime の bopomofo の扱いを直す |

## 3. 作る順番（依存の順）

| 段 | 中身 | 前に要るもの | 終わりの目印 |
|---|---|---|---|
| A | 名前替え（Centaur IME）を main に | 全体試験 | main と配布ページが新しい名前 |
| B | 芯を固める（英語の表を配る形、索引を小さく） | — | 組み立て済みの表が 20 MB 以下、読み込み 0.5 秒以下 |
| C | 日本語の IME オフ → 英語の補完と直し | B | 素通しと遅れが変わらない（測る）、パスワード欄で必ず素通し |
| D | 共通の窓口（TSF）で英語版を単独で | B、C の候補の窓 | 英語版を入れて Notepad・ブラウザ・Word で動く |
| E | 共通の箱（言語パック） | D | 1 つのインストーラーで日本語と英語を選んで入れられる |
| F | 韓国語版 | D、E | 分かち書き・英語モードの見分けが窓口で動く |
| G | 中国語版（Rime ＋ 手がかり） | D、E | 悪くなる所 0 の手がかりが入る |
| H | 中国語の小さな模型 | G、学習（Colab、要相談） | 確かめの文で Rime より字の誤りが少ない |
| I | 候補の言語（ヒンディー語 → アラビア語 → ベトナム語 …） | D、E、模型の作り方 | 言語ごとの計測で目標を超える |

日本語の改善（07-japanese-next.md）は、どの段とも並べて進める。

## 4. 変えない決まり

- 変換を遅くしない。速くする話は speed-claims、採るときは optimization-adoption の決まりを通す。
- main に入れる前は全体試験。言語ごとの計測は「悪くなった所」を必ず数える（06-measurement.md）。
- 芯を書き替えたら、試作（Python）との一致の試験を通す（英語・ハングル・Telex は済み）。
- 材料: 測るだけなら公開の材料は条件を問わない。配る表・模型は著作権法 30 条の 4 に基づき、契約で縛られたものは避ける。
- 公開、導入、Colab、送信などは先にユーザーに聞く。
