Centaur IME English（試用版）

英語を打つときに、単語の補完（Tab で入れる）と、打ち間違いの直しの候補を出します。
キーはそのままアプリに届きます。勝手に文字を直すことはありません。
パスワード欄、ターミナル、リモートデスクトップなどでは動きません。

入れ方:   管理者の PowerShell で install.ps1
外し方:   管理者の PowerShell で uninstall.ps1
使い方:   設定 → 時刻と言語 → 言語と地域 → 英語（米国）→ キーボードの追加 → Centaur IME English
