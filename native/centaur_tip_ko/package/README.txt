Centaur IME Korean（試用版）

2 ボル式（두벌식）で韓国語を打つ入力方式です。
- 한/영 キー、または Shift+Space で韓国語と英語を切り替えます（切り替えるとカーソルの下に 가 / A が出ます）。
- 英語のまま韓国語を打ってしまったとき（dkssud）は、カーソルの下に 안녕 が出ます。Tab で入れ替えて、韓国語に戻ります。
- 韓国語のままブランド名を打ったとき（iphone → ㅑㅔㅗㅐㅜㄷ）は、iPhone が出ます。Tab で入れ替えます。
- 勝手に文字を直すことはありません（直すのは Tab を押したときだけ）。
- パスワード欄、メールアドレス・URL の欄、ターミナル、リモートデスクトップなどでは英字のままです。

入れ方:   管理者の PowerShell で install.ps1
外し方:   管理者の PowerShell で uninstall.ps1
使い方:   設定 → 時刻と言語 → 言語と地域 → 韓国語 → キーボードの追加 → Centaur IME Korean

語の表は Tatoeba（https://tatoeba.org、CC BY 2.0 FR。表示: Tatoeba の投稿者）の韓国語と英語の文と、
韓国語ウィキペディア（CC BY-SA 4.0）から作っています。ブランド名の表は Wikidata（CC0）と手で作った表です。
